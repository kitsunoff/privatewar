# Visual prompts

Prompts for an image generator (GPT) to visualise the UI described in `../10-frontend.md` and `../08-lobby.md`.

How to use:

1. Copy the prompt block from `00-style.md`.
2. Append the prompt block of one screen file.
3. Generate. Iterate on the screen block, keep the style block unchanged so all screens match.

Rules for every prompt: original style, no real game logos, names or trademarks; fictional placeholder names only.
